# EgorBot

Учебный Telegram-бот на Python, использующий внешние API для получения информации и взаимодействия с пользователем.

## Возможности

Бот предоставляет несколько сценариев взаимодействия:

* отправка случайных позитивных мыслей;
* получение прогноза погоды;
* получение информации о расписании поездов;
* получение информации о рейсах;
* использование Telegram-клавиатуры для выбора действий;
* обработка данных, полученных от внешних API.

## Внешние API

Для получения информации бот взаимодействует с внешними сервисами через HTTP-запросы.

Полученные данные обрабатываются и преобразуются в сообщения для пользователя.

## Технологии

* Python
* Telegram Bot API
* `pyTelegramBotAPI`
* `requests`
* REST API
* JSON
* работа с файлами

## Структура проекта

```text
egorbot/
├── main.py
├── positive_thoughts.txt
└── README.md
```

* `main.py` — основная логика Telegram-бота;
* `positive_thoughts.txt` — набор позитивных сообщений;
* `README.md` — описание проекта.

## Результат

В рамках проекта реализован Telegram-бот с несколькими сценариями взаимодействия и интеграцией внешних API.

Проект позволил на практике изучить создание Telegram-ботов, работу с HTTP-запросами и JSON-данными, интеграцию сторонних API и обработку пользовательских команд.
